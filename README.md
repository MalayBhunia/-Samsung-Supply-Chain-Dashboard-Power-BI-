# 📊 Samsung Supply Chain Dashboard (Power BI)

 ## 🚀 Project Overview:

This project is a **Samsung Supply Chain Analytics Dashboard** built using **Power BI**.
It provides a complete view of the supply chain including **Sales, Production, Procurement, Shipment, and Supplier Performance**.

🔍 The dashboard helps to:

* Track key KPIs in real time
* Identify inefficiencies
* Improve operational decisions
* Optimize overall supply chain performance

## 📌 Dashboard Pages

### 🟦 1. Sales Overview

* Gross Revenue
* Net Revenue
* Profit
* Profit Margin %
* Discount Rate %
* Monthly Sales Trend
* Product-wise Sales Analysis

### 🟩 2. Production Analysis

* Total Production Quantity
* Defective Units
* Defect Rate %
* Production Efficiency
* Batch-wise Production Analysis
* Facility Performance

### 🟨 3. Procurement Insights

* Total Procurement Cost
* Cost per Unit
* Average Lead Time
* Supplier Quality Score
* Purchase Order Analysis

### 🟥 4. Shipment & Delivery

* On-Time Delivery %
* Delayed Shipments
* Cost per Shipment
* Cost per Kg
* Delivery Trend
* Delay Reason Analysis

### 🟪 5. Supplier Performance

* Supplier Quality Score
* Average Lead Time
* Supplier Tier Analysis
* Country-wise Distribution
* Top & Bottom Suppliers

## 📊 Key KPIs
